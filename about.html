方法论 · 数据口径 · 披露政策

Agent 情报局的榜单口径、数据来源、更新机制与广告/联盟披露政策：排序不受商业合作影响，编码维度按 OpenLM Chatbot Arena+ 的 Coding Elo 换算。

榜单怎么排

榜单默认顺序 = OpenLM Chatbot Arena+ 页面默认行序（按各产品已上榜旗舰模型在该榜的排名先后排列，未收录者沉底按编辑部评分排）；编码维度按 Arena+ 的 Coding Elo 换算（来源见榜单下方基准表）；无自研模型的产品（Cursor/Copilot/Trae/Devin/Manus/扣子/Perplexity/Poe/腾讯元器）与未上榜的讯飞星火，及其余全部维度为编辑部人工评分（0-10），综合公开基准、社区实测反馈与编辑体验。

基准数据来源

编码维度换算自 OpenLM · Chatbot Arena+ 的 Coding Elo，核实于 2026-09-30；每产品取其已上榜旗舰模型。 站内 基准榜全量快照（324 个模型）抓取于 2026-09-30，行序与源页面一致，未做重排。 其余六个维度为编辑部评分（0-10），依据公开能力实测与产品文档，主观分均明确标注"编辑部"口径。

更新与纠错机制

价格与事件每周五自动巡检 + 人工核实；每条数据标注核实日期与来源链接，超过 14 天未复核的档案会显示黄色提示。发现出入可在任意档案页底部"提交纠错"，反馈每周处理，采纳后在周简报鸣谢。

广告与联盟披露

现状：本站目前没有任何广告位、联盟（返佣）链接或付费排名。智能体收录与否、排序先后，均不接受商业置换。

未来政策：若引入联盟链接，将逐条明示"含推广链接"；若开放赞助位，将整块标注"推广"并与榜单区隔。任何商业合作都不改变榜单顺序与评分——排序只认基准数据与编辑部口径，此承诺可被页面快照历史比对。

社区投票：人气投票只代表社区偏好，与编辑部榜单完全独立，互不影响。
